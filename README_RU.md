# ЖАЙХУН MARKET — стартовый проект v2

Это исходный код демонстрационного MVP, а не готовый коммерческий сервис.

## Что уже подготовлено
- Backend на FastAPI.
- PostgreSQL через Docker Compose (по умолчанию).
- Модели магазинов, товаров, остатков, заказов и позиций заказа.
- API каталога, создания заказа и изменения статуса.
- Начальные демонстрационные категории и товары.
- Flutter-клиент: стартовый экран каталога и корзина (пока локальная демонстрация).

## Важно
- Реальная SMS-авторизация, онлайн-оплата, GPS-отслеживание, push-уведомления,
  загрузка фото, роли сотрудников и production-защита ещё НЕ подключены.
- В API пока нет полноценной авторизации. Не публикуйте сервер в интернете
  и не используйте реальные персональные данные до добавления защиты.
- Цены и товары в демо-данных условные.
- В проекте предусмотрен один магазин на старте и возможность добавлять другие.

## Запуск backend на компьютере
Нужны Docker и Docker Compose.

1. Распакуйте архив.
2. Откройте терминал в папке проекта.
3. Выполните:
   `docker compose up --build`
4. Откройте документацию API:
   `http://localhost:8000/docs`

Backend использует PostgreSQL из docker-compose.

## Запуск Flutter-приложения
Нужны Flutter SDK и Android SDK на компьютере.

1. Перейдите в папку `android`.
2. Выполните `flutter pub get`.
3. Подключите Android-телефон с включённой отладкой USB или запустите эмулятор.
4. Выполните `flutter run`.

Для сборки APK:
`flutter build apk --release`

## Настройка адреса API
По умолчанию Flutter обращается к `http://10.0.2.2:8000` (Android-эмулятор).
Для реального телефона укажите локальный IP компьютера в сети Wi-Fi, например:
`http://192.168.1.10:8000`

## Следующие обязательные этапы до запуска
1. SMS-провайдер и безопасные OTP-сессии.
2. Авторизация и роли: владелец, администратор, продавец, курьер, покупатель.
3. Проверка наличия и цены на момент заказа в транзакции БД.
4. Загрузка фотографий в объектное хранилище.
5. Платёжный провайдер и проверка webhook.
6. Push-уведомления и карта курьера.
7. Журнал действий, резервные копии, мониторинг, HTTPS и тестирование.
