# ЖАЙХУН MARKET V3 — подготовка облачной сборки APK

Это демонстрационный Flutter-клиент с автономным каталогом. Он может открываться без сервера,
чтобы посмотреть внешний вид и базовую навигацию. Реальные заказы, SMS, оплата и доставка
пока не подключены.

## Как получить APK через GitHub Actions с телефона

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в репозиторий всё содержимое этой папки (не сам ZIP).
3. Откройте вкладку Actions и разрешите запуск workflows, если GitHub попросит.
4. Запустите workflow `Build Android APK` через кнопку Run workflow.
5. После завершения откройте выполненный workflow и скачайте артефакт `jayhun-market-debug-apk`.

Для этого шага понадобится аккаунт GitHub. Не загружайте сюда пароли, SMS-коды, данные клиентов
или реальные коммерческие секреты.

## Важно
- Это debug APK для тестового просмотра, не публикационная версия.
- Облачная сборка может потребовать исправления ошибок зависимостей/SDK.
- APK ещё не проверен на реальном устройстве.
- Серверный API пока не подключён к демонстрационному каталогу.
- Не принимайте реальные заказы через этот образец.

## Структура
- `android/` — Flutter-проект.
- `android/lib/main.dart` — приложение с демо-каталогом.
- `.github/workflows/android-apk.yml` — сценарий облачной сборки.
